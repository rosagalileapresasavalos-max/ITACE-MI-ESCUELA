# ITACE-MI-ESCUELA
# ITACE Mi Escuela — proyecto web

## Archivos
- `index.html`: estructura y contenido del sitio.
- `style.css`: estilos visuales.
- `script.js`: menú, tema claro/oscuro, galería, audio, videos, cuestionario y directorio.
- `datos/docentes.json`: datos del directorio docente.
- `imagenes/`, `video/`, `audio/`: coloca aquí los recursos multimedia que correspondan.

## Directorio docente
El buscador acepta nombre, materia, academia, semestre y perfil. El filtro de academia se genera a partir de `datos/docentes.json`. Para que funcione, publica el sitio con Live Server o GitHub Pages (no abras el HTML como `file://`).

## Medios
Las rutas de imágenes y videos son ejemplos/recursos del proyecto. Si algún archivo no está disponible, reemplaza la ruta por el archivo autorizado correcto. Para el video de proyectos se usa `video/desarrollo-web.mp4`.

## Publicación
Mantén las carpetas `datos`, `imagenes`, `video` y `audio` junto a `index.html`, `style.css` y `script.js`. Sube toda la estructura al repositorio.

##Objetivo del proyecto
El objetivo de este proyecto es presentar información sobre el ITACE, sus instalaciones, especialidades y actividades escolares mediante una página web organizada, atractiva y fácil de utilizar.

## Nota
Es una propuesta escolar no oficial. Los datos académicos deben revisarse con el plantel antes de publicar. Se conservaron las descripciones tal como fueron proporcionadas cuando faltaban datos o había términos por confirmar.

##Conclusión
Este proyecto me permitió aprender y aplicar conocimientos de HTML, CSS y JavaScript para crear una página web informativa sobre mi escuela. También aprendí a organizar archivos y publicar un sitio utilizando GitHub Pages.
